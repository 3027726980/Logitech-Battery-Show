# 电量弹出卡片 UI 优化实施计划

**目标：** 优化任务栏左键弹出的电量卡片，让设备身份、连接状态、电量主值和电量条形成清晰的视觉层级，同时保持现有 WinForms 行为和数据逻辑。

**架构：** 仅调整 `BatteryPopup` 的布局、颜色、边框绘制和状态文案，并扩展现有 `BatteryBar` 的绘制能力。保持 `UpdateReading` 的数据来源不变，不引入第三方依赖，不改变托盘点击与关闭行为。

**技术栈：** C#、.NET Framework 4.8、WinForms、GDI+。

---

### 任务 1：重排弹出卡片的视觉层级

**文件：**
- 修改：`src/BatteryPopup.cs`

- [ ] 将卡片尺寸调整为约 286×176，增加安全留白；顶部放置设备名和状态徽标，中部放置大号电量和电量条，底部保留弱化操作提示。
- [ ] 为状态徽标增加统一的圆点和颜色，在线使用绿色，充电使用绿色强调，离线使用灰色。
- [ ] 调整字体、边框、背景和间距，确保标题不会与主电量或电量条重叠。
- [ ] 保留原有外部点击关闭、任务栏附近定位和刷新回调行为。

### 任务 2：增强状态与电量条的呈现

**文件：**
- 修改：`src/BatteryPopup.cs`

- [ ] 将在线状态文案压缩为清晰的连接来源与使用状态组合，例如“LIGHTSPEED · 使用中”和“USB · 充电中”。
- [ ] 离线时显示“鼠标休眠 / 离线”或“未检测到设备”，电量主值使用灰色并避免伪造有效百分比。
- [ ] 继续保持非充电电量条静态灰白填充、充电绿色流光与闪电图标。
- [ ] 给电量条补充更明确的轨道边界和一致的圆角，避免低电量时填充块视觉上脱离轨道。
